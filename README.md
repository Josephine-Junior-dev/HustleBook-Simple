# HustleBook Simple

A mobile-first sales, stock, and expense tracker designed for small businesses in Kenya.

## Features in this first UI version
- Business setup and profile
- Record sales with M-Pesa, cash, bank, or credit
- Track stock and low-stock alerts
- Record and review expenses
- Sales and business summaries
- Customer balances and supplier list
- Export records to CSV
- Mobile-friendly interface

## Important data note
This first version stores its records in the browser's local storage on the current device. It does **not** yet sync records between phones or save them to Supabase. Connect and test the database before using it as the only record of a real business.

## Run it
Open `index.html` in a browser, or enable GitHub Pages for this repository. On GitHub, go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save. GitHub Pages may take a few minutes to publish.
